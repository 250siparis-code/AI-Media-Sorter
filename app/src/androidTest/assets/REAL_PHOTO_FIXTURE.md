# Photographic decoder fixture

`real_photo_fruits.jpg` is the unmodified OpenCV 4.10.0 sample `samples/data/fruits.jpg`, Git blob `a89b84a58487c8db5a71c65b0c1050d498b801d9`.
Source: https://github.com/opencv/opencv/blob/4.10.0/samples/data/fruits.jpg
License: Apache-2.0, https://github.com/opencv/opencv/blob/4.10.0/LICENSE .
This public, non-personal photographic JPEG is packaged in the instrumentation APK only. Tests use mocked Gemini responses and measure decoding, request construction, state and safety; they do not measure visual model accuracy.
